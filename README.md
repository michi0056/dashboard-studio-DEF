# Dashboard di studio

Dashboard personale per lo studio universitario: timer con modalità modificabili, compiti, calendario, esami, abitudini, obiettivi, crescita, diario, note, musica (cartella locale, Spotify, YouTube), meteo di Napoli e un sistema di livelli 1–100 con ranghi G→SSS.

## Uso

Apri `index.html` nel browser. I dati restano nel browser (localStorage). Per la musica, scegli la cartella con i brani: il browser non la ricorda tra una sessione e l'altra.

## Prossimi passi

- Sincronizzazione con Firebase
- Accesso con email e password
